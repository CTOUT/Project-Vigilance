# Security Policy

## Supported Versions

Only the latest development version is actively maintained and receives security updates.

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report them privately via GitHub's private vulnerability reporting on this repository.

Include:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You can expect an acknowledgement within **7 days** and a resolution or mitigation plan within **30 days**.
